question: "¿Qué necesito para empezar a jugar a Superhéroes INC?"
tags: ["reglas-basicas", "inicio"]
category: "Primeros Pasos"
order: 1
---

Para empezar a jugar a Superhéroes INC necesitas:

1. **El libro básico de Superhéroes INC (3ª Edición)** - Contiene todas las reglas necesarias para jugar.
2. **Dados** - El sistema usa dados percentiles (d100) para las tiradas y dados de 1d4, 1d6, 1d8, 1d10, 1d12 y 1d20 para otras mecánicas del juego puedes encontrarlos en tiendas especializadas o comprarlos en tiendas online.
3. **Fichas de personaje** - Puedes descargarlas desde la sección de recursos o usar el [generador de fichas](/recursos/generador-fichas).
4. **Un grupo de juego** - Idealmente de 3 a 6 jugadores más un Guionista (Director de Juego).
5. **Imaginación** - ¡Lo más importante para crear historias épicas!

Opcionalmente, puedes complementar con:
- **Héroe Agenda: Sobrenaturales y Arcanos** - Para personajes mágicos y sobrenaturales.
- **Miniaturas o tokens** - Para visualizar combates.
- **Música ambiental** - Para crear atmósfera.
