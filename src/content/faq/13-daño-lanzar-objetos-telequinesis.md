## Respuesta corta

Se trata como un **arma arrojadiza o proyectil**.  
El daño se calcula sumando **daño base del objeto**, **modificador por material** y **modificador por potencia**, usando **rango ×2** para consultar la tabla de potencia.
## Respuesta larga

Cuando un objeto es lanzado mediante telequinesis, su impacto se resuelve igual que el de un arma arrojadiza o un proyectil convencional.

El daño final se obtiene combinando tres elementos:

1. **Daño base del objeto**  
    Se utiliza el daño correspondiente al objeto como arma improvisada o, si procede, el del arma concreta (manual básico, **pág. 127**).
    
2. **Modificador por material**  
    El material del objeto lanzado añade su modificador correspondiente (piedra, metal, hormigón, etc.) (manual básico, **pág. 126**).
    
3. **Modificador por potencia telequinética**  
    Para representar la fuerza con la que el objeto es impulsado, se aplica el modificador de potencia consultando la tabla correspondiente, usando **rango ×2** del poder de telequinesis (manual básico, **pág. 126**).

Este sistema permite diferenciar claramente entre lanzar un objeto ligero sin demasiada fuerza y convertir cualquier elemento del entorno en un proyectil realmente peligroso mediante una telequinesis potente.
## Regla / criterio

- El objeto se considera arma arrojadiza/proyectil
    
- Se usa el daño base del objeto o arma improvisada
    
- Se suma el modificador del material
    
- El modificador de potencia se calcula con **rango ×2**
    
- No se aplica el Modificador de Fuerza del personaje

## Ejemplo

Un personaje lanza una **piedra** mediante telequinesis a **rango elevado (60)**.

- Daño base de arma improvisada: **1d6**
    
- Modificador por material (piedra): **+20**
    
- Modificador por potencia: rango ×2 = 120 → **+15**

**Daño total:**  
**1d6 + 20 + 15**
